# Isaac Media Website

Site vitrine multi-pages pour Isaac Media (FR) avec un positionnement orienté conversion:
- Accueil
- Services
- Réalisations
- À propos
- Contact

## Lancer localement

```bash
python3 -m http.server 4173
```

Puis ouvrez: `http://localhost:4173`

## Stack

- HTML5
- CSS3
- JavaScript vanilla
